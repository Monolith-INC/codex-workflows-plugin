# Merge Story Stack Into Feature

Follow `skills/merge-story-stack-into-feature/SKILL.md`. Inspect feature and story pull requests through the SCM adapter, merge stories into the feature branch oldest→newest with merge commits only (never squash), reconcile remaining descendants after each landing, and publish merge evidence to the tracker. Do not open Feature→trunk.
